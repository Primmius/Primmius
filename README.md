## 🚀 Flagship Project: InkTwin

[**InkTwin (inktwin.primuez.in)**](https://inktwin.primuez.in) is an open-source AI platform that converts digital text into realistic, handwritten pages and synthesizes personal handwriting into fully custom OTF/TTF fonts using computer vision and multimodal LLMs.

- ✍️ **Font Synthesis Engine:** Converts handwriting sample photos into functional digital font glyphs.
- 🧠 **Gemini Multimodal Solver:** AI-assisted homework & assignment study engine generating answers directly in your personalized handwriting.
- ⚡ **Tech Stack:** React 18, TypeScript, Tailwind CSS, Vite, Supabase, Cloudflare Workers, AGPL-3.0.
- 📦 **Repository:** [Primmius/Ink-Twin](https://github.com/Primmius/Ink-Twin)
