## 🚀 Flagship SaaS: InkTwin

[**InkTwin (inktwin.primuez.in)**](https://inktwin.primuez.in) is an open-source AI platform that turns digital text into realistic, organic handwritten documents and synthesizes personal handwriting samples into fully functional **custom vector OTF/TTF fonts** using computer vision and multimodal LLMs.

- ✍️ **Font Synthesis Engine:** Converts handwriting sample photos into functional digital font glyphs with baseline and ligature alignment.
- 🧠 **Gemini Multimodal Solver:** AI-assisted homework & assignment study engine generating answers directly in your personalized handwriting.
- ⚡ **Edge & Serverless Stack:** React 18, TypeScript, Tailwind CSS, Vite, Cloudflare Workers, Hono, D1 SQL, R2 CDN, AGPL-3.0.
- 📦 **Source Repository:** [Primmius/Ink-Twin](https://github.com/Primmius/Ink-Twin)
